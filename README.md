# 何か？
[OpenSUSI](https://opensusi.org/)が公開している[東海理化シャトル向けのオープンPDKリポジトリ](https://github.com/OpenSUSI/TK-1um.git)から(openIP62_rev1.0)[https://github.com/OpenSUSI/TK-1um/tree/main/openIP62_rev1.0]を抜き出して[OpenRule1umPDK_setupEDA](https://github.com/ishi-kai/OpenRule1umPDK_setupEDA.git)用に書き換えたものです。  
[OpenRule1umPDK_setupEDA](https://github.com/ishi-kai/OpenRule1umPDK_setupEDA.git)の[pdk_TR10-setup.sh](https://github.com/ishi-kai/OpenRule1umPDK_setupEDA/blob/main/pdk_TR10-setup.sh)スクリプト経由でご利用ください。
